# テキスト欄とファイルの対応

| 番号 | Connectの欄 | 上限 |
|---|---|---|
| 01 | App名 | 30文字 |
| 02 | サブタイトル | 30文字 |
| 03 | プロモーション用テキスト | 170文字 |
| 04 | キーワード | 100 UTF-8 bytes以内で保守的に検証 |
| 05 | 概要 | 4000文字 |
| 06 | このバージョンの最新情報 | 4000文字。初回は不要 |
| 07 | サポートURL | 公開して疎通確認するHTTPS URL |
| 08 | マーケティングURL | 任意の紹介ページ |
| 09 | Copyright | 年と実際の権利者名 |
| 10 | App Reviewメモ | 非公開。レビュー手順 |
| 11 | プライバシーポリシーURL | 必須。公開するHTTPS URL |

日本語のコピー用テキストです。URLとCopyrightは共通publisher.jsonから生成します。未設定の欄は空になります。レビュー連絡先は非公開欄へ入力します。READMEや申告案を説明文欄へ貼らないでください。名前・SKU・Bundle IDの使用可否はConnectで確認が必要です。
